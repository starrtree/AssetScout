# Portable prompt and learning contract

## Prompt packet

Include original human wording; business goal; audience; brand; conversion; labeled assumptions.

Record source freshness: canonical Sheet, fetch timestamp, live/snapshot mode, exact source titles/URLs/tab/rows and provenance. Embed selected excerpts. Keep visual and code selection scopes distinct.

Give three directions with composition/hierarchy, material/geometry, typography, palette/light, motion/camera, fallback and complexity. Explain the choice while retaining rejected alternatives. Tag source-derived terms versus new synthesis.

Define interactions as trigger → element → bounded behavior → timing/parameters → exit/reset → reduced-motion/touch fallback.

Identify exact selected asset/repo/component, official docs, version/commit if verified, installation constraints and license evidence. Mark unknown versions. Include compatibility across framework/React, dependencies, WebGL ownership, GPU, mobile, accessibility, reduced motion, licensing, difficulty and production readiness. Separate evidence, inference and measurements.

Recommend the smallest stack, proposed budgets, semantic/keyboard/contrast requirements, media rights, anti-patterns, acceptance tests and build order.

Use the label StarrTree reconstructed prompt unless a separate exact original quote is genuinely verified. For a three-source cluster, exported inspiration contains exactly those sources; visibly selected code assets may be separate. Changing cluster or brief invalidates prior directions/prompts.

## Pattern candidate

Begin as unverified_candidate. Capture screenshot/preview; project/client; original references; final successful prompt; actual technology stack; repository/commit; desktop/mobile results; performance notes; implementation problems; what worked; reusable variables/parameters; human approval; canonical Motherboard record link.

An exported JSON is a review artifact, not an independent resource database. Read the latest Motherboard schema before an authorized write. Record failures and problematic combinations; an impressive screenshot alone is not proof.
